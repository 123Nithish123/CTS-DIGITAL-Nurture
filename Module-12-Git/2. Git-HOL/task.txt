Exercise 2: Setting Up Git Ignore Patterns

Objective:
Generate a .log file and a log directory in your project, then configure .gitignore to exclude them from version control.

Steps:
mkdir GitIgnoreDemo
cd GitIgnoreDemo
git init
echo sample log > app.log
mkdir log
echo *.log > .gitignore
echo log/ >> .gitignore
type .gitignore
git status
git add .gitignore
git commit -m "Add gitignore rules"
