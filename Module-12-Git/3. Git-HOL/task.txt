Exercise 3: Working with Branches and Merging Changes

Objective:
Develop a new branch, implement modifications within it, integrate those changes back into the main branch, and remove the branch once merged.

Steps:
git checkout -b GitNewBranch
git branch -a
git checkout GitNewBranch
echo branch work > branch.txt
git add branch.txt
git commit -m "Add branch work"
git status
git checkout master
git diff master GitNewBranch
git mergetool
git merge GitNewBranch
git log --oneline --graph --decorate
git branch -d GitNewBranch
