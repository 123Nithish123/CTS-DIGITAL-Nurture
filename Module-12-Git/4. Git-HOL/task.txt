Exercise 4: Handling Merge Conflicts

Objective:
Produce conflicting modifications on the main branch and a feature branch, resolve the conflicts, finalize the merge commit, and clean up the branch.

Steps:
git status
git checkout -b GitWork
type nul > hello.xml
echo branch content > hello.xml
git add hello.xml
git commit -m "Add hello.xml on branch"
git checkout master
echo master content > hello.xml
git add hello.xml
git commit -m "Add hello.xml on master"
git log --oneline --graph --decorate --all
git diff master GitWork
git mergetool
git merge GitWork
git add hello.xml
git commit -m "Resolve merge conflict"
git status
echo *.bak >> .gitignore
git add .gitignore
git commit -m "Ignore backup files"
git branch -d GitWork
git log --oneline --graph --decorate
